## 🧑‍💻 About Me

- 🎓 경영정보학을 전공하며 데이터와 비즈니스 흐름을 기반으로 사용자 문제를 분석하고 서비스 관점에서 해결하는 방법을 학습했습니다.
- 🤖 생성형 AI, AI Agent, RAG 기반 서비스 등 AI 기술이 실제 사용자 경험과 업무 방식에 어떤 변화를 만드는지에 관심을 가지고 있습니다.
- 📊 Python·SQL 기반 데이터 처리 및 자동화 프로젝트를 수행하며 기획부터 구현까지 연결되는 문제 해결 경험을 쌓았습니다.
- 🧭 사용자의 불편과 서비스 내 병목 지점을 발견하고, 더 나은 사용자 여정(User Journey)으로 개선하는 과정에 흥미를 느낍니다.
- 🚀 단순 기능 구현을 넘어, AI 기술을 활용해 기업의 AX(AI Transformation)와 서비스 혁신에 기여하는 기획자를 목표로 성장하고 있습니다.

> 단순히 기술을 적용하는 것이 아니라,  
> 사용자의 행동과 흐름 속에서  
> “무엇이 불편한가, 어떻게 더 나은 경험을 만들 수 있는가”를 고민합니다.
